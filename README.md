# Clarté d'âme — site

Page d'accueil et documents légaux (politique de confidentialité, CGV, mentions légales) de l'application Clarté d'âme, publiés avec GitHub Pages.

Les pages sont générées à partir des textes de l'application (`npm run build-site` dans le dépôt de l'appli) : ne pas les modifier à la main ici.
